# Katkı Rehberi

1. Aktif task ve `AGENTS.md` dosyasını okuyun.
2. Değişiklikten önce `git status --short --branch`, `ackit scan` ve ilgili preflight kontrollerini çalıştırın.
3. Secret, OTP, token, kişisel veri veya production credential commit etmeyin.
4. Değişikliği küçük tutun ve davranış değişikliği için focused test ekleyin.
5. Göndermeden önce `npm run verify` çalıştırın ve sonucu task/handoff belgesine yazın.
